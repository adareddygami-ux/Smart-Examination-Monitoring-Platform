# Milestone 2 Testing Report

This document contains the validation scenarios and test cases executed to verify the Integrity Analytics Platform's continuous monitoring features.

| Test Case ID | Test Scenario | Input | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|
| TC-01 | Normal Candidate | Face present, no tab switching, no focus loss, normal interaction. | Few/no violations generated. Integrity score remains high. | As expected. | PASS |
| TC-02 | Tab Switching (Threshold Check) | Candidate switches tab 1 time, 2 times, and 4 times. | 1-3 times: Logged as `TAB_SWITCH`, no violation if threshold is 3. 4 times: `EXCESSIVE_TAB_SWITCH` violation generated. | As expected. | PASS |
| TC-03 | Face Absence (Warning) | Candidate leaves camera view for 5 seconds. | `FACE_ABSENT` event logged. `FACE_ABSENCE_WARNING` violation generated. | As expected. | PASS |
| TC-04 | Face Absence (High) | Candidate leaves camera view for 30+ seconds. | `EXTENDED_FACE_ABSENCE` violation generated (High severity). | As expected. | PASS |
| TC-05 | Multiple Faces | Two or more faces placed in the camera frame. | `MULTIPLE_FACES` logged. `MULTIPLE_FACE_DETECTION` violation generated. | As expected. | PASS |
| TC-06 | Focus Loss | Candidate switches away from examination window (clicks desktop). | `FOCUS_LOST` and `FOCUS_GAINED` events logged with duration. Violation generated if exceeding threshold. | As expected. | PASS |
| TC-07 | Combined Events | Face absent + Tab switch + Focus loss within the same session. | `COMBINED_SUSPICIOUS_ACTIVITY` violation generated by the Rule Engine. | As expected. | PASS |
| TC-08 | Session Completion & Cleanup | Candidate submits exam. | Camera stops, monitoring stops, events are saved, violations appear on dashboard, K-Means clustering runs, and session history updates. | As expected. | PASS |
